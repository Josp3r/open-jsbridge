协议优先、三端一致的 Hybrid JSBridge 标准

Open JSBridge 定义了跨 WebView 与原生宿主的异步 JSON-RPC 2.0 信封规范、能力协商与安全隔离模型。所有宿主注入同一份 window.__OJSB_TRANSPORT__ 契约，Web 业务只写一份代码。

三层解耦架构与工程红线

Transport 通道差异由各平台 Host Shim 吸收；Envelope 与 Semantics 在 Web、iOS、Android、Flutter 与 React Native 之间保持一致。

01 / SPEC-FIRST

单一事实来源

所有信封与方法以 spec/ JSON Schema 为准，CI 通过 codegen:check 拦截类型与契约漂移。

02 / ASYNC-ONLY

异步、超时与取消

拒绝同步 prompt() 劫持。每次调用具备 deadline，支持 AbortSignal 与 bridge.cancel 释放原生槽位。

03 / DEFAULT SECURE

默认拒绝与文档隔离

精确 HTTPS origin + main frame + document + sid 强校验；缺少安全通道时返回 null，绝不启用不安全回退。

04 / CAPABILITIES

能力协商而非猜版本

握手返回已启用的方法、事件与特性列表，前端用 bridge.has() 检测，新增业务能力走厂商命名空间。
